# Abfahrten

## config

Configuration happens via environment variables or a `.env` file.

Parameters:

| name     | description                                       | content                             |
| -------- | ------------------------------------------------- | ----------------------------------- |
| RUST_LOG | set the log level                                 | `RUST_LOG=[target][=][level][,...]` |
| STATIONS | List of all stations to cache                     |                                     |
| CORS     | enable CORS and set the header to the given value |                                     |
